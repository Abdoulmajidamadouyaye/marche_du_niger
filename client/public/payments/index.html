Ajouter les logos des modes de paiement

Les logos affiches dans l'interface utilisent actuellement ces fichiers SVG dans client/public/payments/:

  • visa.jpg pour la carte Visa
  • mynita.png pour MyNITA
  • amana.png pour AmanaTa

Vous pouvez remplacer ces SVG par vos propres visuels en gardant les memes noms. Ils seront disponibles via les chemins publics:

  • /payments/visa.jpg
  • /payments/mynita.png
  • /payments/amana.png
